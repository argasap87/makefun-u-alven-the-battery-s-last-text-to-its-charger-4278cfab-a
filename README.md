**The battery's last text to its charger** — *"I'm at 1% while you 'optimize charging' — enjoy the outlet, I'm seeing a power bank behind your back."*

The charger kept "optimizing" all day while the battery waited at 1% — so the battery is done waiting and is seeing a power bank behind the charger's back. A cheating-affair breakup text, from a battery with nothing left to lose.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

Writes the one-line entry (101 characters) to `/output/entry.txt`. Node 22+ stdlib only — no network, no external files.
